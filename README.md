# 🏦 ATM Interface (Java Swing)

## 📌 About the Project

The ATM Interface is a GUI-based desktop application developed using Java Swing. It simulates basic ATM operations and allows users to perform banking transactions through an interactive graphical user interface.

Users can log in using their User ID and PIN and access different banking functionalities.

## ✨ Features

- User ID and PIN-based authentication
- Secure login system
- Account balance inquiry
- Cash withdrawal
- Cash deposit
- Fund transfer
- Transaction history
- Account access restriction after 3 incorrect PIN attempts
- User-friendly graphical interface

## 🛠️ Technologies Used

- Java
- Java Swing
- Java AWT
- Object-Oriented Programming (OOP)
- ArrayList

## 🏗️ Project Structure

The project is organized into multiple Java classes:

- **Main.java** – Application entry point
- **LoginFrame.java** – User login interface
- **ATMFrame.java** – ATM dashboard and operations
- **Bank.java** – Banking operations management
- **Account.java** – Account details and balance management
- **Transaction.java** – Transaction records

## ⚙️ How to Run the Project

### Prerequisites
- Java Development Kit (JDK)
- Visual Studio Code or any Java-supported IDE

### Steps

1. Clone the repository:


   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Open the terminal inside the project source folder.

4. Compile the Java files:


   javac *.java
   ```

5. Run the application:

   java Main
   ```
